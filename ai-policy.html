AI Usage Policy

This course is about building agents that use AI to perform software engineering tasks, and using AI tools effectively is one of the skills it aims to develop. We will therefore be permissive about the use of AI when writing code, but some parts of the course must be your own work. This page explains what is allowed for each part of the course and why. We will also discuss this policy in class during the first week. If anything is unclear, ask the Instructor before using an AI tool, not after.

Course Project: Code

You may use AI tools freely when writing code for the course project. This includes chatbots, coding assistants, and coding agents. Learning to work with such tools, prompting them effectively, and critically evaluating what they produce is part of what this course is meant to teach. Working with existing coding agents is also a good way to learn how agents are designed and where they fall short.

However, you are responsible for all code that you submit, regardless of who or what wrote it. Every team member should be able to explain how your agent works and why it was designed that way. Expect to be asked about your code during the mid-semester review and the final presentation. In your final report, briefly describe which AI tools you used and how you used them.

Project Proposal, Final Report, and Presentation Slides

The project proposal, the final report, and all presentation slides (for both your paper presentations and your final project presentation) must be created by you, without the use of AI tools. The only exception is that you may use spell-checkers and grammar checkers (but not features of such tools that generate or rewrite text for you).

These are where you show your own understanding: of the papers you present, and of the design of your agent, the choices you made, and what you learned from evaluating it. Being able to communicate these things clearly in your own words is an important skill, and it is something that an AI tool cannot do for you.

In-Class Written Answers

The handwritten answers to questions about the assigned papers are written in class with pencil and paper. No electronic devices (laptops, tablets, phones, etc.) may be used while writing them, unless approved as an accommodation. These answers are meant to reflect your own reading and understanding of the papers.

If You Prefer Not to Use AI Tools

You are not required to use AI tools to write code for the project. If you have concerns about using them, please talk to the Instructor early in the semester.

Violations

Using AI tools in ways that this policy does not allow is a violation of the course's Academic Integrity policy, and will be handled accordingly.

Use of AI in Course Materials

AI tools were used to help build this course website. The Instructor has reviewed all of its content.
